Because Windows is case-insensitive, changing only:

to:

can be problematic.

Think of it like this
Windows can treat these two names as the same:

So if you tell Git:

when the underlying branch is currently stored as string, Windows may effectively say:

"You already have something called String — that's the same thing as string."

Git may therefore not perform a clean filesystem-level rename.

We force the name to become completely different first:

Step 2
